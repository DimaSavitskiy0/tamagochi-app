# scripts/ — локальные инструменты (не часть приложения)

Всё в этой папке, кроме этого файла, не коммитится в git (см. `.gitignore`) — это
инструменты только для этого Mac, не для приложения и не для сервера.

## «Секрет для сервера.app»

Двойной клик в Finder — **терминал не открывается**, только два нативных окошка
macOS: выбрать переменную (или ввести своё имя) → вставить значение → готово.
Значение уходит с этого Mac прямо на сервер по SSH (`root@62.113.44.88`, ключ
`~/.ssh/lapgo_vps`) — не через чат с Claude, Claude его не видит. Приложение само
обновляет `/opt/tamagochi-backend/.env` и пересобирает/перезапускает API-контейнер.

Работает для любого секрета сервера — RuStore Push/webhook токены, Anthropic API-ключ,
SMTP-пароль и т.д. Если нужной переменной нет в списке — выберите «Другое» и впишите
имя вручную (как в `server/.env.example`).

Если Finder ругается на «неизвестного разработчика» при первом запуске — правый клик по
файлу → «Открыть» (один раз, дальше открывается обычным двойным кликом).
